# Family Aquarium — reset password page

Requires the earlier forgot-password patch and the Better Auth `sendResetPassword` callback configured on the API.

From repository root, extract this ZIP then run:

```bash
bash apply-reset.sh
pnpm --filter @aquarium/web typecheck
```

Test: open `/forgot-password`, request an email, inspect Mailpit at http://localhost:8025, follow the reset link, set a new password, then log in.

The reset link must be generated by Better Auth using `redirectTo: ${window.location.origin}/reset-password` on the request. Do not create your own reset tokens.
